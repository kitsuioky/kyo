If you wish to remove Kyo from your system, you can uninstall the `kyo` or `kyo-git` package using your distribution's package manager.

### Manual Installation

If you installed manually using `just install release`, remove the files installed under your prefix:

```bash
rm ~/.local/bin/kyo
rm -rf ~/.local/share/kyo
```

## Cleaning Up

After removing the package, you may want to remove the configuration and cache files.

### Configuration and Cache

Kyo stores its configuration and cache in the standard XDG directories. To remove them:

```bash
rm -rf ~/.local/state/kyo
rm -rf ~/.cache/kyo
```

### Generated Templates

If you enabled any templates in the **Color Scheme** settings, you will need to manually delete the generated files.
